[ ECOSSISTEMA DE PROJETOS // V2.0 ]

COGITO ERGO SUM

Penso, logo existo.

Um espaço para transformar curiosidade em projetos, conectar tecnologia e criatividade e compartilhar o que aprendemos.

> PROJETO ATUAL

Silent Breach

Conscientização em cibersegurança por meio de palestra, demonstrações controladas e interação com o público.

O CyberDeck/PLOT é a ferramenta física de apoio dessa experiência.

CONHEÇA O PROJETOTECNOLOGIAS

01 // Silent Breach

A tecnologia chama a atenção. A conversa transforma essa curiosidade em cuidado no dia a dia: reconhecer riscos, questionar mensagens e proteger informações.

Palestra

Uma conversa sobre engenharia social, golpes digitais e hábitos que ajudam a proteger contas e dados.

CONSCIENTIZAÇÃO

Demonstrações controladas

Exemplos em ambiente autorizado para tornar riscos digitais visíveis e explicar como se prevenir.

APRENDER NA PRÁTICA

Interação com o público

Perguntas, reflexão e um quiz para conectar os temas apresentados às decisões do cotidiano.

PARTICIPAÇÃO

CyberDeck / PLOT

Um notebook reaproveitado dá suporte físico às apresentações e demonstrações. O PLOT integra essa experiência como ferramenta: o projeto Silent Breach reúne também conteúdo, comunicação e participação do público.

02 // Tecnologias

Hardware reaproveitado

Notebook reaproveitado na composição do CyberDeck/PLOT, com montagem voltada ao apoio das demonstrações.

Kali Linux

Ambiente de apoio ao estudo e às demonstrações de cibersegurança em cenários controlados.

Ferramentas de demonstração

Nmap, netcat e scripts personalizados, já citados na base do projeto, para explorar conceitos de rede em ambiente local autorizado.

Plataforma web

HTML, CSS e JavaScript no site; GitHub Pages para publicação e repositório GitHub para acompanhar o código.
