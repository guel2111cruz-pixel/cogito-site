TESTE COM WIRESHARK // ANÁLISE DE TRÁFEGO

PERÍODO: 01/10/2026
RELATO: Miguel (GL)
AMBIENTE INFORMADO: PLOT e A15 com Termux

No teste, utilizamos o comando wireshark no PLOT para abrir o analisador de pacotes.

No Wireshark, aplicamos o filtro de exibição ip.addr==10.0.0.56 para selecionar os pacotes IPv4 capturados cujo endereço de origem ou destino fosse 10.0.0.56.

O filtro permite concentrar a análise no endereço utilizado no teste, mas não limita os pacotes à porta 8080. Ele altera apenas a exibição dos pacotes presentes na captura.

Resultado: o comando e o filtro utilizados foram informados por Miguel (GL). A interface selecionada, os pacotes observados e os resultados da análise ainda não foram registrados neste diário.

REFERÊNCIA TÉCNICA: Wireshark — campo ip.addr ↗ · Filtros de exibição ↗

TESTE COM NMAP // DESCOBERTA DE HOSTS E SERVIÇO HTTP

PERÍODO: 01/10/2026
RELATO: Miguel (GL)
AMBIENTE INFORMADO: Rede 10.0.0.0/24, A15 com Termux e PLOT

Iniciamos com nmap -sn 10.0.0.0/24, para descobrir os hosts que respondiam às sondagens na faixa indicada. A opção -sn realiza descoberta de hosts sem a etapa de varredura de portas.

Em seguida, utilizamos nmap -sV 10.0.0.56, para verificar o alvo e tentar identificar os serviços e suas versões nas portas encontradas abertas.

No A15, pelo Termux, utilizamos python -m http.server 8080 para iniciar um servidor HTTP na porta 8080. Por padrão, esse servidor disponibiliza o diretório em que o comando é executado.

Para a verificação no PLOT, o comando foi informado como nmap -sV -p 10.0.0.56:8080. Essa forma não é válida para indicar o alvo e a porta no Nmap: a opção -p recebe as portas, e o endereço do alvo fica separado.

Correção técnica do comando: nmap -sV -p 8080 10.0.0.56. Essa forma verifica a porta TCP 8080 do alvo e tenta identificar o serviço e sua versão. A execução dessa forma corrigida ainda não foi confirmada no relato.

Resultado: os comandos acima foram informados por Miguel (GL). As saídas do Nmap, a quantidade de hosts encontrados, o estado observado da porta 8080 e a identificação do serviço ainda não foram registrados. A abertura da porta não comprova, por si só, uma vulnerabilidade.

REFERÊNCIAS TÉCNICAS: Nmap — descoberta de hosts ↗ · Detecção de serviços ↗ · Especificação de portas ↗ · Python — servidor HTTP ↗
