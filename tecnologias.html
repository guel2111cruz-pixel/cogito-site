TECNOLOGIAS UTILIZADAS

Hardware:

Tablet Xiaomi Redmi Pad 2, ESP8266/ESP32, Módulo NFC (PN532 ou RC522), Cartões NFC, Teclado e Mouse Bluetooth.

Software Base:

Termux, Ubuntu via XFCE4, X11, Shell Script, Python, C++ (ESP), Arduino IDE.

Segurança:

Autenticação multifator (NFC + senha), camadas de permissão, comunicação criptografada via rede local.

Rede:

Rede privada local no dia da feira, comunicação ESP ↔ Tablet via TCP/IP, scripts de varredura (nmap, netstat).

Ferramentas de hacking ético:

Kali Linux (WSL), nmap, hydra, netcat, scripts personalizados em Python.

Front-end do site:

HTML5, CSS3, JavaScript puro. Hospedagem no GitHub Pages.
